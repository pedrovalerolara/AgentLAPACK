# AgentLAPACK

Artifact repository for the AgentLAPACK paper.

This repository is composed of the next atifacts:
- VisionLAPACK: 
- - setup.sh - Set up the program in a python virtual environment
- - visionlapack.py - Train and testing VisionLAPACK
- ChatLAPACK:
- - The ChatHPC assistant ChatLAPACK can be created by following the documentation available in the ChatHPC website (https://ornl.github.io/ChatHPC/) and reposiory (https://github.com/ORNL/ChatHPC-app), and the data provided in this repository.

Also, this repository is composed of the necessary data to be used for training (fine-tuning):
- Examples of the VisionLAPACK images (matrix equations) can be found in the /VisionLAPACK/VisionLAPACK-data/ folder
- Examples of the ChatLAPACK HPC codes can be found in the /ChatLAPACK/ChatLAPACK-data-examples folder
